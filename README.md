# مخططي 3D — Mokhatiti-3D

تطبيق Android أصلي باللغة العربية لتخطيط المنازل والتصميم الداخلي، موجّه للهاتف والتابلت.

## المسار التقني المعتمد

- Kotlin وAndroid Views.
- محرر 2D أصلي باستخدام Android Canvas.
- عرض 3D أصلي باستخدام OpenGL ES 2.0.
- لا يوجد WebView أو HTML أو JavaScript في مسار تشغيل الفرع Native.

## الميزات الموجودة في فرع التطوير

الفرع: `feat/native-sweethome3d-core-port`

- رسم الجدران بوحدات مترية مع سماكة وارتفاع لكل جدار.
- الالتقاط لنقاط نهاية الجدران والمحاذاة الأفقية والرأسية.
- تحديد الجدران وتحريكها وحذفها والتراجع عن التعديلات.
- تكبير وتصغير وتحريك مساحة الرسم بإصبعين.
- اكتشاف الغرف المغلقة من شبكة الجدران، بما فيها الغرف المتجاورة.
- إضافة أبواب ونوافذ إلى الجدران مع فتحات فعلية في مجسمات الجدران.
- إنشاء طوابق متعددة مع حفظ مناسيبها وعرضها متراكبة في 3D.
- مكتبة أولية لأثاث أساسي (أريكة، أسرّة، طاولة، كرسي، خزانة) مع وضعه وتحريكه.
- تعديل سماكة الجدار وارتفاعه.
- عرض مساحات الغرف في 2D و3D.
- حفظ محلي واستيراد وتصدير JSON عبر منتقي ملفات Android.
- اختبارات هندسية للقياسات والغرف والفتحات والأثاث.

## ما لم يكتمل بعد

هذا الفرع **ليس إصداراً احترافياً نهائياً** ولا يمثل نقلاً كاملاً لمحرك Sweet Home 3D. ما زالت هناك أعمال أساسية، منها:

- مكتبة أثاث ثلاثية الأبعاد تفصيلية بدلاً من المجسمات الكتلية الأولية.
- تعديل اتجاه فتح الأبواب والنوافذ وإطاراتها وأبعادها.
- الجدران المنحنية والوصلات الهندسية المتقدمة.
- السلالم والأسقف وأدوات إدارة الطوابق المتقدمة.
- الأبعاد والقيود الهندسية والأدوات الدقيقة.
- الإضاءة والظلال والخامات والمواد.
- إدارة عدة مشاريع واستعادة الإصدارات.
- تصدير CAD والطباعة.
- اختبارات تفاعلية وأداء على هواتف وأجهزة لوحية فعلية.

## البناء والتحقق

يشغّل GitHub Actions اختبارات JVM، ويبني APK، ويتحقق من الملف، ثم يثبته ويشغله على محاكي Android. لا يُعد البناء إصداراً نهائياً إلا بعد نجاح أحدث تشغيل CI واختبارات التفاعل الفعلية على الهاتف والتابلت.

## التراخيص

لا تُستخدم واجهة Sweet Home 3D JS أو WebView في هذا الفرع. أي شفرة أو مكتبة أو نموذج أو خامة يتم اقتباسها من Sweet Home 3D أو غيره يجب أن تخضع لمراجعة ترخيصها مع الحفاظ على إشعارات المصدر وشروط التوزيع.
