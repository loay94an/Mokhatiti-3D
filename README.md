# مخططي 3D — Mokhatiti-3D

تطبيق Android عربي لتصميم المنازل والتخطيط الداخلي، يستهدف الهاتف والتابلت.

## المسار المعتمد

المحرك المعتمد هو **Sweet Home 3D JS 7.5.2 الأصلي**، وليس محركاً هندسياً جديداً يُعاد بناؤه من الصفر. سيُحافظ على منطق التصميم والعرض 2D/3D الخاص بالمصدر، مع طبقة Android محلية للتشغيل والملفات واللمس وواجهة عربية.

مرجع المصدر: [lurume84/SweetHome3D](https://github.com/lurume84/SweetHome3D) — مرآة Git غير رسمية لمصدر Sweet Home 3D المستضاف أصلاً على SourceForge. المسار المستخدم هو `SweetHome3DJS/` مع مصدر `SweetHome3D/` الذي يعتمد عليه.

## مبادئ لا يجوز تجاوزها

1. عدم استبدال محرك Sweet Home 3D JS بمحرك Canvas/OpenGL مستقل.
2. عدم حذف ميزات المحرك أو تقديم واجهة شكلية على أنها محرر مكتمل.
3. تضمين ملفات التشغيل محلياً قدر الإمكان، وعدم جعل الإنترنت شرطاً لفتح المشاريع.
4. دعم فتح وحفظ ملفات `.sh3d` من مساحة Android.
5. عدم قلب المخطط أو اتجاهات القياس عند تفعيل RTL.
6. لا يُعلن اكتمال أي ميزة قبل اختبارها فعلياً.
7. لا يُنشأ APK أثناء التطوير؛ البناء النهائي يأتي بعد اجتياز بوابات القبول.
