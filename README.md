# مخططي 3D — Mokhatiti-3D

تطبيق Android عربي لتخطيط المنازل والتصميم الداخلي، موجّه للهاتف والتابلت.

## المسار المعتمد
الإصدار الأصلي Native باستخدام Kotlin وAndroid Views. لا يعتمد مسار التشغيل على WebView أو HTML أو JavaScript.

## ما تم تنفيذه في فرع native-engine-foundation
- واجهة Android أصلية باللغة العربية واتجاه RTL.
- مساحة رسم 2D أصلية تدعم إضافة مقاطع الجدران بالسحب.
- تراجع ومسح للمخطط.
- حفظ وفتح نموذج المخطط محلياً بصيغة JSON داخل مساحة التطبيق.
- معاينة محورية مجسمة أولية Native مشتقة من نموذج المشروع.
- خط بناء APK مستقل لا يقوم بتنزيل أو تجميع محرك الويب السابق.
- فحص تشغيل أولي على محاكي Android ضمن GitHub Actions.

## الحالة بصراحة
هذه **قاعدة Native أولية قابلة للتطوير وليست إصداراً احترافياً مكتملاً**. معاينة 3D الحالية تمثيل محوري أولي وليست بعد محرك CAD ثلاثي الأبعاد كاملاً. كما أن أدوات الأبواب والنوافذ والأثاث والطوابق والأبعاد الدقيقة والاستيراد والتصدير المتقدم واختبارات اللمس والأداء ما زالت ضمن العمل.

لن يُعلن اكتمال التطبيق قبل تنفيذ واختبار هذه الوظائف فعلياً على الهاتف والتابلت.

## خارطة العمل
1. تثبيت نموذج هندسي موحد بوحدات مترية وإحداثيات مستقلة عن الشاشة.
2. تطوير محرر 2D: الجدران المتصلة، الالتقاط للشبكة، القياسات، التحديد والتحريك والتعديل.
3. إنشاء محرك 3D حقيقي بكاميرا قابلة للدوران والتكبير ومواد وأسطح وفتحات.
4. إضافة الأبواب والنوافذ والسلالم والأثاث والطوابق.
5. إدارة المشاريع والنسخ التلقائي والحفظ والاستعادة.
6. التصدير والطباعة ومشاركة المخططات.
7. اختبارات آلية ووظيفية على أحجام شاشات متعددة وأجهزة Android فعلية.

## البناء
يُبنى APK عبر GitHub Actions عند الدفع إلى فرع `native-engine-foundation` أو `main`. ملف APK التجريبي يظهر ضمن Artifacts بعد نجاح البناء والاختبار.

## التراخيص
كانت النسخة السابقة تحتوي على ملفات وموارد Sweet Home 3D JS. لا يستخدم التطبيق Native الحالي هذه الموارد في مسار التشغيل. يجب مراجعة تراخيص أي مكتبة أو أصل هندسي قبل دمجه مستقبلاً.
