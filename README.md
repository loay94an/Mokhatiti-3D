# مخططي 3D — Mokhatiti-3D

تطبيق تخطيط المنازل والتصميم الداخلي باللغة العربية، يستهدف الهواتف والأجهزة اللوحية بنظام Android.

## الهدف
محرر فعلي للمخططات ثنائية الأبعاد مع معاينة ثلاثية الأبعاد متزامنة، وحفظ محلي وقياسات دقيقة.

**تنبيه:** لا يوجد APK جاهز في هذه المرحلة. لن نعتبر واجهة تجريبية بديلاً عن محرك التصميم الفعلي.

## الوظائف المستهدفة
- رسم الجدران والغرف والأبواب والنوافذ.
- عرض 2D و3D متزامن.
- مكتبة أثاث وعناصر داخلية.
- القياسات بالمتر والسنتيمتر والطوابق المتعددة.
- حفظ وفتح المشاريع محلياً.
- واجهة عربية RTL كاملة.

## المصدر المفتوح
المحرك المرشح هو Sweet Home 3D JS. راجع `docs/ENGINE-INTEGRATION.md` والتزم بنص GPL وإشعارات حقوق النشر وتراخيص المكونات والنماذج.

## البناء
سيضاف إعداد Gradle وGitHub Actions بعد تثبيت طريقة دمج المحرك والتحقق من ملفات البناء الفعلية.
